# 企微会话存档双模式本地模拟器操作指南

## 适用边界

本工具只用于本地开发。自建应用模式会执行 RSA 解包、逐消息 AES-256-GCM 解密和媒体分片；第三方代开发模式会执行授权夹具、逐消息密钥解包和展示组件回读。它证明本地协议合同与 MoChat 生产代码路径可用，不代表真实企业微信线上环境已经通过。

模拟器只向 bridge 的上游夹具写入数据，不直接写最终消息表或媒体表。最终业务数据由 app 内的 durable worker 拉取、解析并提交。

## 启动

在仓库根目录执行：

```powershell
docker compose -p mochat-go-desktop --profile app -f deploy/standalone/docker-compose.yml up -d --build
```

应用入口为 `http://127.0.0.1:18080`。bridge 是同一 Compose 项目中的独立容器，不暴露宿主机端口。

## 初始化一个租户的模拟上游

租户必须已经存在唯一企业绑定，命令中的模式必须和租户开户时选择的权威模式一致。

```powershell
docker compose -p mochat-go-desktop --profile app --profile archive-fixture -f deploy/standalone/docker-compose.yml run --rm archive-simulator seed --enable-simulation --tenant-id 2 --mode self_built --dataset MOCHAT-LOCAL-SIM-demo
```

第三方代开发租户将 `--mode` 改为 `third_party_delegated`。重复执行相同命令是幂等的。

## 发送文本消息

```powershell
docker compose -p mochat-go-desktop --profile app --profile archive-fixture -f deploy/standalone/docker-compose.yml run --rm archive-simulator send --enable-simulation --tenant-id 2 --mode self_built --dataset MOCHAT-LOCAL-SIM-demo --type text --text "本地模拟消息"
```

## 发送图片、录音、视频或文件

先把去敏文件放到 `deploy/standalone/fixtures`，然后执行：

```powershell
docker compose -p mochat-go-desktop --profile app --profile archive-fixture -f deploy/standalone/docker-compose.yml run --rm archive-simulator send --enable-simulation --tenant-id 2 --mode self_built --dataset MOCHAT-LOCAL-SIM-demo --type image --file /fixtures/input/sample.png
```

`--type` 可选 `image`、`voice`、`video`、`file`。第三方代开发模式下，媒体正文只进入本地展示组件，不会落到普通媒体对象存储。

## 触发同步与查看

发送后可等待后台周期任务，也可在 Dashboard 的“唯一企业资料 → 数据同步”点击“立即同步会话”。同步成功后，在会话页面查看文本或鉴权媒体；第三方代开发消息使用“安全查看会话内容”打开 60 秒一次性展示会话。

查看模拟器上游状态：

```powershell
docker compose -p mochat-go-desktop --profile app --profile archive-fixture -f deploy/standalone/docker-compose.yml run --rm archive-simulator status --enable-simulation
```

## 清理

不传精确确认值时，清理命令不会执行：

```powershell
docker compose -p mochat-go-desktop --profile app --profile archive-fixture -f deploy/standalone/docker-compose.yml run --rm archive-simulator cleanup --enable-simulation --tenant-id 2 --mode self_built --dataset MOCHAT-LOCAL-SIM-demo --confirm-dataset MOCHAT-LOCAL-SIM-demo
```

清理范围绑定到租户、企业、模式和数据集；不会删除其他租户或没有 `MOCHAT-LOCAL-SIM-` 标记的数据。
