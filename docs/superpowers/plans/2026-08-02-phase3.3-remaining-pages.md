# Phase 3.3 剩余页面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 Phase 3.3 剩余菜单页面的路由接入、真实接口复用、状态处理、测试和部署验证。

**Architecture:** 继续复用现有 Dashboard shell、React Query、`PageState` 和页面注册表。对已有后端契约的页面接入真实 API；对尚无 provider 或任务接口的页面提供真实筛选入口、权限/空数据/未接入状态，不制造演示业务数据或假下载链接。

**Tech Stack:** React、TypeScript、React Query、现有 `business-workbench` API、Vitest、Docker Compose。

## Global Constraints

- 所有页面必须包含加载、空数据、无权限/未接入、服务异常和刷新状态。
- 会话存档、媒体、导出和风险命中数据不得伪造；没有后端契约时必须在页面中明确说明。
- 继续使用现有企业/租户权限上下文，不绕过 `DashboardAccessProvider`。
- Docker 更新不得执行 `down -v`，必须保留现有 MySQL、Redis、应用存储和审计锚点数据卷。
- 每个批次遵循 RED → GREEN → 集成验证 → 浏览器截图 → 独立提交。
