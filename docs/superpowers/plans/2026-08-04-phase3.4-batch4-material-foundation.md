# Phase 3.4 第四批素材底座实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将素材管理从 placeholder 升级为具备真实企业隔离、作用域、分组、批量操作、引用保护和统一选择合同的 Phase 3.4 原生页面，并完成九页阶段验收。

**Architecture:** 在现有 `mc_medium`/`mc_medium_group` 与 Dashboard handler 上做兼容扩展，新增批量和选择器 handler；React 侧新增独立 `phase34/material-management` 功能目录，通过 `BusinessWorkbenchApi` 适配既有 envelope。写操作统一由认证会话解析企业和操作者，跨页面只共享素材 ID 与只读选择合同。

**Tech Stack:** Go 1.26、MariaDB 10.6、React 19、TypeScript、TanStack Query、Vitest、Testing Library、Docker Compose。

## Global Constraints

- 不接受客户端提交 `corp_id`，所有读写从认证会话解析企业。
- 旧素材兼容为 `scope_type=public`、`scope_id=0`、`sidebar_visible=1`、`status=available`。
- 删除前必须引用检查；存在引用返回 `409`，不得硬删除。
- 文件素材只复用现有上传 Provider，不伪造上传成功或外部同步。
- 所有新增行为先写失败测试并观察预期失败，再实现最小代码。
- 不修改或清理 `.workbuddy/`、`web/saas-admin/` 和用户既有未跟踪文件。
