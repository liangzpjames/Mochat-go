# Phase 3.4 第三批内容触达页面实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建设精准群发与朋友圈两个原生页面，精准群发接入真实双 Provider 查询，朋友圈如实呈现 Provider 阻断边界。

**Architecture:** 新建独立 `content-reach-pages.tsx`，用共享标签页、筛选区、列表和详情结构承载两页。精准群发按活动标签切换 `/contactMessageBatchSend/index` 与 `/roomMessageBatchSend/index`；朋友圈只渲染已观察的信息架构，不调用不存在的发布、导出或素材 Provider。

**Tech Stack:** React 19、TypeScript、TanStack Query、Vitest、Testing Library、现有 Dashboard CSS 与 `BusinessWorkbenchApi`。

## Global Constraints

- 不使用 fixture、演示任务或伪成功状态。
- 自动化环境禁止真实群发、提醒和朋友圈发布。
- 保留 `mochat-go-desktop` 数据卷；部署只重建 `app` 服务。
- 用户验收文档、界面文案与报告使用中文。
