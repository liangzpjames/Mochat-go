# 数据概览圆弧 AI 风格重构设计

## 1. 背景

当前数据概览已经接入经营快照、客户增长、客户/客户群会话和 AI 洞察数据，但页面仍然沿用“说明文字 + 大模块 + 明细表”的组织方式。圆弧 AI 参考页采用更适合快速判断的控件组：短标题、紧凑指标、左右分栏图表和局部状态提示。

本次重构以圆弧 AI 的信息密度和视觉组织为参考，但不复制其数据。所有内容必须来自 MoChat 自身接口；接口未返回、Provider 未接入或数据受限时，界面显示告警，不使用示例值或默认零值掩盖缺失。

## 2. 目标与边界

### 目标

- 重组数据概览页面结构，允许移除不必要的旧模块。
- 用紧凑指标控件替代大段说明文字，支持快速扫读。
- 会话数据采用左侧客户/客户群指标控件、右侧趋势柱状图的组合。
- AI 洞察拆分为多个简短控件，保留真实 AI 摘要入口。
- 对暂时没有真实数据源的质检、员工排行、轨迹等模块显示明确告警。
- 保持日期筛选、刷新、导出和分页能力。

### 非目标

- 本轮不为质检、员工排行、员工轨迹新增虚假数据。
- 本轮不复制圆弧 AI 的品牌、业务数据或外部接口。
- 本轮不删除后端已有报告能力；只调整概览页面的呈现和缺失数据语义。

## 3. 参考界面提炼

- 页面采用浅色背景、白色卡片、细边框、圆角和较大的留白。
- 每个业务区先用简短标题和筛选控件定位范围，再展示少量高价值指标。
- 指标区用多个同规格小卡片，数字比说明文字突出。
- 图表与指标同卡片左右排列，图表使用浅网格、单一主色柱状图和底部日期。
- 无数据时保留模块位置，使用空状态插画/提示文字，不用 0 填充。
- 详情通过按钮或链接进入，不把完整分析文本直接堆在首页。

## 4. 页面结构

```text
数据概览
├─ 顶部范围栏：日期范围 / 查询 / 刷新 / 导出
├─ 数据状态栏：更新时间 + Provider 限制告警（有才显示）
├─ 经营快照：4 个紧凑指标卡
├─ AI 洞察：4 个短信息控件 + 查看详情
├─ 客户增长趋势：趋势范围 + 柱状图
├─ 会话数据：左侧客户会话/客户群控件 + 右侧趋势柱状图
├─ 质检数据：真实数据卡；无字段时显示能力未接入告警
└─ 员工排行/会话轨迹：真实数据卡；无字段时显示数据源待补齐告警
```

旧的“近七日会话趋势明细”表格和“经营趋势明细”分页表格都从首页移除。首页导出仍保留完整趋势数据，明细查看交给导出或专门报表页，不抢占概览判断空间。

## 5. 数据契约与真实性规则

### 5.1 缺失值语义

概览 API 解析层不再把缺失或 `null` 数值转换为 `0`。数据类型允许 `number | null`：

- 接口明确返回数字 `0`：展示 `0`。
- 接口返回数字：展示该数字。
- 接口字段缺失或返回 `null`：展示 `--`，并在模块中显示数据告警。
- Provider 出现在 `limitations`：显示 Provider 名称、原始限制信息和恢复提示。

### 5.2 模块数据映射

| 页面模块 | 真实来源 | 当前状态 |
| --- | --- | --- |
| 经营快照 | `/reports/overview.summary` | 已有 |
| 客户增长趋势 | `/reports/overview.series` | 已有 |
| 客户/客户群会话 | `/reports/overview.conversation` | 已有，受会话归档 Provider 影响 |
| AI 洞察 | `/reports/overview.aiInsight` | 已有，能力可能未接入 |
| 质检数据 | 当前概览响应没有对应字段 | 显示能力未接入告警 |
| 员工会话排行 | 当前概览响应没有对应字段 | 显示数据源待补齐告警 |
| 员工会话轨迹 | 当前概览响应没有对应字段 | 显示数据源待补齐告警 |

### 5.3 告警状态

统一使用 `OverviewDataNotice` 表达三类状态：

- `limited`：接口返回限制，展示原始限制信息。
- `unavailable`：能力或 Provider 未接入，展示恢复条件。
- `empty`：数据源可用但当前筛选范围没有记录，提示调整范围或补充业务数据。

告警组件不展示虚构的统计数字，也不把“暂无数据”和“真实为 0”混为一谈。

## 6. 组件边界

- `OverviewDataNotice`：统一告警、空状态和恢复提示。
- `OverviewSnapshot`：只接收快照指标，负责紧凑卡片布局。
- `OverviewAIInsightGrid`：把真实 AI 摘要拆成短卡片；详细文本仍通过已有详情链接查看。
- `OverviewConversationPanel`：左侧切换客户会话/客户群，右侧渲染趋势柱状图；数据缺失时由 `OverviewDataNotice` 接管。
- `OverviewTrendChart`：只负责真实趋势点和日期标签，不负责制造缺失点。
- `OverviewCapabilityPanel`：承载质检、员工排行、轨迹等当前没有字段的控件和告警，后续接入字段时只替换数据适配层。

## 7. 交互与响应式

- 日期范围、刷新、导出继续使用现有接口和查询参数。
- 会话左侧控件切换只改变右侧趋势，不改变数据来源。
- AI 洞察首页只展示短摘要和状态，点击“查看 AI 洞察”进入详情页。
- 桌面端使用双栏；宽度不足时按“指标控件 → 图表 → 能力告警”的顺序纵向堆叠。
- 柱状图日期使用不截断的完整日期；超过容器宽度时允许横向滚动，不裁切底部标签。

## 8. 验收标准

- 页面视觉组织接近圆弧 AI：控件组装、留白、指标密度和图表布局一致，但数据全部来自 MoChat。
- AI 洞察首页不再出现大段连续文字。
- 会话数据左侧为可切换指标控件，右侧为趋势柱状图。
- 任何缺失模块都能看到明确告警，且没有把缺失值显示成 0。
- 真实 0 仍显示为 0。
- 现有查询、刷新、导出、分页和权限范围不回归。
- 桌面、390px 移动宽度和 reduced-motion 场景均无布局溢出。
