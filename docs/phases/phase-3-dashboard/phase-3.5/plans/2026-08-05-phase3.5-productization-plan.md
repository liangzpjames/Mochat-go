# Phase 3.5 产品化实施计划

> **开发任务要求：** 必须使用 `executing-plans` 技能逐项执行本计划，并用复选框（`- [ ]`）记录进度。

**Goal:** 将 Phase 3.5 九个基础骨架页面升级为与现有 MoChat 风格统一、具备真实数据闭环和完整状态体验的可验收页面。

**Architecture:** 保留现有 reporting/SCRM API 边界，新增共享展示层组件、中文指标字典和可下钻明细模型；仅在真实工作流缺少合同能力时扩充后端。实施按“共享框架 → SCRM 页面 → 报表页面 → 验收数据与证据”推进。

**Tech Stack:** React 19、TypeScript、TanStack Query、Ant Design、Go、MariaDB、Vitest、Go testing。

## Global Constraints

- 开发任务禁止部署、重建 Docker、修改 Compose 或删除任何 volume。
- 主任务只负责设计与审核；开发任务完成或遇到阻塞必须通知主任务。
- 不在 C 盘创建缓存或输出；验收证据使用 `D:\workspace\mochat-go\output\phase35-productization`。
- 禁止 fixture/demo/placeholder 进入生产路径。
- 禁止直接显示内部指标 key；所有文案使用中文业务名称。
- 必须保留 tenant/corp/RBAC/数据范围边界。
