**Goal:** 在保留 `mochat-go-desktop` 现有 Docker 数据卷的前提下，交付 Phase 3.5 的 4 个 SCRM 扩展页与 5 个真实数据报表页。

**Architecture:** 复用现有 SCRM、企微客户/群、会话和营销数据，通过统一 Phase 3.5 服务端合同向 React 页面提供汇总、趋势、维度、明细、新鲜度和限制状态。订单/设置只在现有模型无法承载时增加最小 migration。

**Tech Stack:** Go、MariaDB/MySQL 5.7 兼容 SQL、React 19、TypeScript、Vitest、Playwright、pnpm、Docker Compose。

## Global Constraints

- 固定范围为 9 个设计文档列出的路由，不提前纳入 Phase 3.6。
- 所有查询同时限制 tenant、corp 和当前用户数据范围；禁止姓名关联。
- 生产页面禁止 fixture、demo、placeholder 和静态成功结果。
- 指标必须遵守事件时间、租户时区、去重、分母和迟到事件规则。
- Docker compose project 必须为 `mochat-go-desktop`；禁止删除或替换任何现有 volume。
