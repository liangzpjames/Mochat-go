# 沉默客户与拒绝存档 Provider 设计

## 沉默客户

规则定义沉默天数、适用范围和启停状态。客户活跃度接入接口提交客户最后互动时间，Provider 按启用规则生成或刷新沉默记录；记录支持分派、标记跟进、唤醒成功、忽略和关闭，所有动作留存审计。页面分为沉默记录和规则配置两个页签。

## 拒绝存档

授权状态接入接口提交员工、客户或群成员的会话存档授权快照。`refused` 状态进入拒绝名单，`authorized`、`pending` 和 `expired` 更新同一主体的当前状态；人工操作只允许记录跟进和备注，不允许客户端伪造授权结果。页面提供状态筛选、详情和跟进记录。

## 共同边界

数据按租户和企业隔离；同步接入接口受独立权限控制。页面不生成演示记录。历史处置和授权变化均以审计表保存。沉默计算使用调用方提供的真实客户活跃时间，拒绝存档使用会话存档系统或回调提供的真实授权状态。
