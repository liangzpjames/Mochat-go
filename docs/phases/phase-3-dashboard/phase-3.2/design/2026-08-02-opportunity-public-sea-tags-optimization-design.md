# 商机、公海与客户标签页面优化设计

## 范围与参照

本轮仅优化 `/customer/opportunity`、`/customer/public-sea`、`/customer/tags`。功能和信息层级以圆弧实际页面为参照，但只呈现当前 SCRM API 已支持的真实能力，不伪造导出、批量删除、系统标签或群聊标签数据。

## 页面设计

- 商机保留组合筛选、创建、阶段推进、赢单、输单原因和跟进记录，强化销售协同页头、状态概览、列表刷新和业务信息层级。
- 公海保留来源、业务类型、标签、地区、原因和前负责人筛选，强化客户流转页头、回收摘要、单个与批量领取以及审计历史展示。
- 客户标签增加与圆弧一致的标签类型导航。企业标签为真实可操作目录；系统标签和群聊标签以禁用状态明确表示后端暂不支持。标签组、标签维护、联系人关联和删除预览继续使用真实接口。

## 一致性与验证

三页复用线索池与联系人的渐变页头、统计卡、筛选区、数据卡、刷新工具栏、空态和错误重试样式。筛选继续由 URL 驱动，写操作继续遵守权限、版本和幂等约束。采用测试先行，并执行目标测试、Dashboard 全量测试、类型检查、生产构建和浏览器验收。
