# 全局消息页面优化设计

## 范围

本轮只处理 `/chat/v2-all`。员工会话、客户会话、群聊会话及其他会话页面不在本轮范围。

## 设计

- 保留现有真实会话归档查询、分页和详情接口，不伪造统计数据。
- 参照圆弧页面的信息层级，增加结果摘要、会话类型快捷筛选、刷新入口，并统一筛选区、结果区和未授权状态的视觉表达。
- 菜单维持现有路由结构，仅强化“会话”展开状态及“全局消息”选中态。
- 企业未开通会话存档时，保留明确的授权引导；有权限时展示真实结果和详情抽屉。
- 所有筛选条件继续写入 URL，以支持刷新恢复、前进后退和可复现查询。

## 验收

- 页面具备关键词、会话对象、员工、日期筛选及重置。
- 页面具备真实结果数、类型快捷筛选、刷新、分页和详情查看。
- loading、empty、403、归档未授权、错误及详情 404 状态均有统一呈现。
- 桌面端视觉层级接近圆弧，窄屏下筛选区和结果区不溢出。
