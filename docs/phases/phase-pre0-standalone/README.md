# Phase Pre-0：独立版与 SaaS 能力收口

## 阶段状态

已完成。该阶段形成 MoChat Go 独立运行、SaaS 总后台 MVP、发布候选和生产证据门禁，后续不再以追加式阶段报告驱动开发。

## 实施前状态

项目仍以从原系统迁移和补齐独立运行能力为主，功能缺口、发布候选、生产准备和 SaaS 治理记录分散在长篇追加文档中。

## 阶段目标

- 建立不依赖原 PHP runtime 的 Go 独立版。
- 完成 SaaS 总后台 MVP 与核心治理能力。
- 建立独立部署、验收、生产证据、备份和回滚流程。
- 明确尚不能宣称最终生产完成的外部证据边界。

## 已完成

- Go 独立部署和 standalone compose 链路。
- SaaS Admin MVP 与租户、套餐、审批、告警、审计等治理能力。
- 本地快速门禁、独立包验收和生产候选证据收集机制。
- 发布候选、源码指纹、目标完成度和生产证据检查。

## 未完成与阻塞

- 真实企微、微信开放平台、生产 SaaS 租户和生产前端证据仍需外部环境提供。
- 历史阶段报告体积较大，仅保留为历史事实和证据，不再作为当前进度来源。

## 验收与证据

- `plans/`：发布候选和阶段计划。
- `reports/`：最终阶段报告与缺口历史。
- `evidence/`：本地与生产候选证据。
