# Phase 3.2 数据概览单页优化设计

## 目标

仅优化 `/index`，把当前“筛选器加空态”的页面升级为可直接验收的业务数据驾驶舱。页面覆盖数据概览、AI 洞察、会话数据、质检数据、员工排行和会话轨迹六个区域；无数据时仍展示完整结构和零值，而不是隐藏主体。

## 实现边界

- 保留 `/corpData/index`、现有租户/企业/员工/部门权限范围和 CSV 导出。
- 复用接口已有客户、群、员工和趋势字段；尚无独立数据源的洞察、质检、排行和轨迹明确展示零值或空态，不伪造业务数据。
- 筛选区改成面向用户的日期、团队范围和趋势周期；高级员工/部门 ID 筛选收进可展开区域。
- 使用统一白色卡片、浅灰背景、蓝色主操作、紧凑指标和响应式双栏布局，不逐像素复制圆弧。
- 其余七个 Phase 3.2 页面不修改。

## 验收

页面在有数据和无数据时都具备六个区域；查询、刷新、周期切换、分页与导出继续工作；桌面宽度下层级清晰，窄屏下单列排列；最终以本地 Docker 页面人工验收为准。
