# 敏感词页面优化设计

## 范围

本轮只处理 `/ai-insight/v2/sensitive-word`。风险行为、超时预警、客户流失等其他风险预警页面不在本轮范围。

## 设计

- 保留现有真实命中记录、词组、词条和变更接口，不构造风险等级、AI 摘要、批量审计或导出假数据。
- 风险预警菜单在敏感词路由刷新后自动展开，敏感词保持选中。
- 命中记录增加真实结果摘要、刷新、分页及结构化详情抽屉，筛选继续使用员工、客户群、词组和时间条件。
- 敏感词配置按词组与词条拆分为清晰卡片，保留新增、搜索、改名、启停、移动和删除权限控制。
- loading、empty、403、冲突和配额限制继续使用真实状态与统一反馈。

## 验收

- 记录分区支持筛选、刷新、上一页、下一页和详情关闭。
- 摘要仅展示接口返回的总数、当前页数量和当前词组范围。
- 配置分区保留全部真实变更闭环，视觉层级与记录分区一致。
- 页面在桌面和窄屏下均无控件堆叠或横向破版。
